Welcome to auto-incucyte's documentation!
=========================================

``auto-incucyte`` converts native Incucyte plate exports and a small metadata
table into analysis-ready data, baseline-normalized plots, and an audit proving
how normalization was performed.

Start with :doc:`quickstart` to run the bundled synthetic example. Read
:doc:`inputs` before analyzing a new plate layout.
